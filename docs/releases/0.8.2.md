# Tinta Viva 0.8.2

Esta versión corrige un fallo que podía dejar una respuesta vacía aunque Motor Tinta se hubiera activado correctamente.

## Correcciones

- recupera automáticamente el modelo configurado después de reiniciar Tinta Viva o si LM Studio lo descargó de la memoria;
- usa respuestas completas con LM Studio local para evitar una caída observada al generar mediante streaming SSE;
- si Vulkan informa `ErrorDeviceLost`, vuelve a cargar el mismo modelo por CPU y reintenta la respuesta una sola vez;
- conserva streaming para los demás motores compatibles;
- muestra el error real del motor en la interfaz;
- oculta del chat los mensajes fallidos que no contienen texto, sin borrar el historial de la base local;
- mantiene personajes, conversaciones, imágenes y configuración existentes.

## Verificación

- reproducción del error real con LM Studio y DarkIdol 8B;
- prueba de recuperación automática del modelo;
- prueba de generación LM Studio sin streaming;
- suite Release completa.
